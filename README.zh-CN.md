# Fable Short Drama

[English](README.md) | [简体中文](README.zh-CN.md)

使用 Vite、React 和 TypeScript 独立实现的短剧观看界面原型，包含演示账户入口、可搜索的剧集目录、收藏库、剧集详情、播放器预览和会员预览。界面支持英语、简体中文、繁体中文、西班牙语和巴西葡萄牙语。导航、元数据和控件中的紧凑文字统一按 1.1 倍放大，并设置 10px 的最小字号，以提高可读性。

本仓库是前端应用，不包含后端 API、数据库、真实身份认证、视频分发或支付处理。

## 本地运行

使用 Node.js 22.12 或更高版本及 npm，以兼容 `package-lock.json` 中的 Vite 版本。在本仓库根目录执行：

```powershell
npm ci
npm run dev
```

打开 [http://localhost:5174](http://localhost:5174)。开发脚本监听 `0.0.0.0` 并请求使用 `5174` 端口；如果端口已被占用，请以 Vite 输出的实际地址为准。运行此原型无需 `.env` 文件或 API 凭据。

页面通过 Unsplash 加载海报图片，通过 Google Fonts 加载字体，这些资源需要网络连接。

## 使用方式

1. 在初始账户页面选择语言，填写演示邮箱和至少 8 个字符的密码后进入。注册和登录都只执行本地格式校验，不核验已有账户或密码；应用仅在本地保存邮箱，不持久化密码。
2. 浏览主推剧集和目录，按剧名、分类或标签搜索，并使用分类筛选缩小范围。
3. 点击收藏按钮添加或移除剧集，在“我的收藏”中查看已收藏的内容。
4. 打开剧集详情，查看简介和 6 个示例分集按钮。前 3 集打开播放器预览，后续分集在未启用演示会员时打开会员页面。将鼠标悬停在目录海报上，或使用键盘聚焦海报，即可播放静音循环预览；移开鼠标或失去焦点后会暂停并重置。如果远程预览视频加载失败，界面会保留海报显示。
5. 打开“Fable Plus”查看免费和 VIP 权限对比，选择月度或年度方案，并选择 Visa、Mastercard、微信支付或支付宝创建本地演示订单。普通账户可观看每部剧前 3 集，VIP 演示权限会解锁示例分集列表。此操作不收款，也不创建真实订阅。
6. 通过账户页面或登录后的导航栏切换语言。顶部语言菜单保持足够宽度以显示完整选项；点击侧栏退出按钮可返回账户页面。

“热门”按钮目前只显示提示，不改变目录排序。集数、评分和会员价格均为演示数据。

## 工程结构

- `index.html`：页面元信息和 React 入口加载。
- `package.json`：依赖以及开发、构建和预览命令；`package-lock.json` 记录解析后的依赖版本。
- `vite.config.ts`：启用 React 插件；`tsconfig.json` 定义 TypeScript 编译选项。
- `src/main.tsx`：挂载应用。
- `src/vite-env.d.ts`：Vite 客户端和资源类型声明。
- `src/App.tsx`：账户入口、目录、搜索、收藏、剧集详情、海报悬停预览和会员结算界面。
- `src/dramas.ts`：演示剧集目录、海报引用和可选的悬停预览视频地址。
- `src/i18n.ts`：语言检测、界面文案翻译、分类标签翻译和本地化剧集元数据。
- `src/vipApi.ts`：Visa、Mastercard、微信支付和支付宝的本地 VIP 注册及支付适配器契约。
- `src/styles.css`：响应式界面样式。
- `.gitignore`：排除依赖目录、构建产物和 Vite 缓存。
- `README.md`、`README.zh-CN.md`：英文和中文说明文档。

## 配置与本地数据

在 `src/dramas.ts` 修改演示目录和海报引用，在 `src/i18n.ts` 修改翻译及本地化元数据，在 `src/styles.css` 修改外观。开发和预览服务的监听地址及端口在 `package.json` 的脚本中配置。

应用使用以下浏览器 `localStorage` 键：

| 键名 | 保存内容 |
| --- | --- |
| `fable-demo-user` | 当前账户展示使用的演示邮箱 |
| `fable-demo-saved` | 已收藏的剧集 ID |
| `fable-demo-member` | 是否启用会员预览 |
| `fable-demo-locale` | 已选择的语言 |
| `fable-demo-vip-orders` | 结算弹窗创建的本地 VIP 演示订单 |

上述数据按浏览器同源地址保存，不按账户分别隔离。退出登录仅移除演示邮箱，保留收藏、会员预览和语言设置。不同端口使用独立存储；清除此站点的存储会重置演示状态。当前没有服务端同步或用户间数据隔离。

## 支持的语言

- `en`：英语
- `zh-CN`：简体中文
- `zh-TW`：繁体中文
- `es`：西班牙语
- `pt-BR`：巴西葡萄牙语

优先使用已保存的语言。首次访问时根据浏览器语言选择支持的语言，未匹配时使用英语。

## 构建与预览

在仓库根目录执行：

```powershell
npm run build
npm run preview
```

构建命令执行 TypeScript 检查并将静态资源输出到 `dist/`，该目录已被 Git 忽略。预览脚本监听 `0.0.0.0` 并请求使用 `4174` 端口；打开 [http://localhost:4174](http://localhost:4174)，或使用 Vite 输出的实际地址。`vite preview` 用于本地检查构建结果；需要托管演示站时，可将 `dist/` 部署到静态托管服务。

## 正式上线前需要完成

接入身份认证服务、后端剧集目录及数据库、已授权的剧集视频和支付服务。将 `src/vipApi.ts` 中的本地函数替换为 VIP 注册、订单创建和支付确认的服务端调用，为订阅及收藏增加服务端权限校验和按用户持久化。当前账户入口、会员标记和订单适配器不提供访问控制，也不会收取真实款项。服务条款和隐私按钮仅显示提示，上线前需要发布正式法律文档。
